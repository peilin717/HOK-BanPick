# 荣耀赛事台：班级赛使用指南

本项目是基于 qiqi47/HOK_Ban_Pick 改造的国服本地赛事 BP 系统。原始项目和 MIT 许可保留在 Git 历史和根目录 LICENSE.txt 中。英雄资源与音乐来源见 RESOURCES.md。

## 启动

Windows 中双击工作区里的 `start.cmd`，或在 PowerShell 执行：

```powershell
wsl -d Ubuntu -- bash /root/Course_THU/HOK-BP/start.sh
```

等待输出启动地址后，在 Chrome / Edge 打开 `http://localhost:5173`。

脚本会构建当前源码并启动本地静态服务。现有工作区已安装依赖；复制项目到新机器时，需要 Node.js 20.19+（或 22.12+）和第一次联网安装依赖。运行期间保持终端窗口开启。停止服务按 Ctrl+C。

## 一台电脑接大屏

1. Windows 按 Win+P，选择「扩展」。
2. 裁判打开首页：上方是主屏，下方是独立滚动的裁判区。点击「独立投屏」打开纯主屏窗口。
3. 将新窗口拖到教室大屏，点击左下角「启用此窗口声音」和「全屏展示」。全屏时鼠标移到左下角可以再次显示按钮。
4. 音频只在一个窗口播放。如果已经在控制台试音，先停止该窗口声音，再在大屏启用。

两个窗口必须使用**同一浏览器、同一用户配置、相同地址**。不要一个用 localhost、另一个用127.0.0.1；它们的浏览器存储不同。不同电脑不共享比赛，当前设计就是裁判单机控制。

## 开赛准备

在「队伍与赛制」中填写赛事名、两队队名、Logo 和五名选手昵称；选择 BO3/BO5/BO7，每方固定5 Ban（第一轮2个，第二轮3个），设置每手时间并选择是否全局BP。队标支持 PNG、JPG、WebP，会缩放到256×256。

选禁顺序按腾讯官网 KPL 2026 赛事规则 6.1.1 核对，详见 KPL_RULES_2026.md。计时仍为班级赛可配置的每手计时，并未实现官方整队总时限。

## 比赛操作

- 点击英雄预选，再点击「确认禁用／锁定」。可按名称、ID搜索或按官方分路筛选。
- 倒计时由裁判启动，可暂停、重置。计时归零后仍由裁判处理超时，不擅自随机选人。
- 「撤销一手」恢复上一手选禁；已确认胜方后不再允许撤销该局BP。
- BP结束后先进行游戏，待游戏结束再确认本局胜方。系统自动加比分并记入全局用将，然后开始下一局。
- 换边只能在下一局未开始选禁前进行，已用英雄随队伍移动。
- 队名、Logo、选手名和比分可修正。手动修正比分不会伪造历史局记录；应确保显示比分与实际赛果一致。
- 新建系列赛会清空比分、选禁及全局用将，保留队伍信息和主要赛制设置，操作前会确认。

## 全局 BP 与巅峰对决

普通全局 BP：本队之前小局使用过的英雄不可再次选取；对方此前使用过的英雄不因此禁用。Ban不跨局累计，历史已用英雄仍可以在后续小局被Ban。

巅峰对决：仅 BO7 前六局战成 3:3 后，点击「开始下一局」自动进入；BO3/BO5 的决胜局仍采用普通全局 BP。系统核对比分及前六局赛果，双方各填5个英雄。允许双方镜像英雄，解除此前全局用将限制。大屏在裁判点击「揭晓双方阵容」前不显示英雄，不播放选取语音。选手在裁判控制台旁提交阵容时，应避免让对手看到控制台。

## 音乐与语音

内置《Know My Name》社区伴奏版（Nelshare），212.4秒，来源和哈希见 `public/data/bgm.json`。它不是官方分轨版。

- 默认所有阶段使用这首伴奏。浏览器需要先手动点击启用声音。
- 可导入自己的音频到指定阶段；该阶段有专用音乐时优先使用，否则回退到「所有阶段」。
- 多首同阶段音乐打乱后依次播放，减少连续重复。
- 确认Pick时播放该英雄的官方大厅／登场语音，预选和Ban不播放英雄台词。
- 连续锁定的语音排队播放，语音播放期间 BGM 保持设定音量。
- 可分别调整BGM与语音音量、切下一首、重播最近英雄语音或紧急静音。
- 自行导入的音频在浏览器 IndexedDB 中保存，不包含在比赛JSON存档里；内置伴奏和官方英雄媒体保存在项目目录中。

## 存档与恢复

每次操作自动保存到当前浏览器 localStorage。建议每局结束导出JSON存档。刷新裁判页面会恢复比赛并暂停、重置本手计时，避免恢复时倒计时已经归零；重新打开大屏会读取当前正在运行的计时。

导入会校验英雄ID、选禁顺序、重复选取、全局限制和比赛状态；无效存档不会覆盖当前比赛。不要清除浏览器站点数据，也不要在无痕窗口里举办长期系列赛。

## 更新国服资源

```bash
cd /root/Course_THU/HOK-BP
python3 scripts/sync-assets.py
python3 scripts/sync-assets.py --verify
```

同步采用腾讯官方国服名单和新版官方语音接口。更新后重新启动构建即可载入新资源。2026-10-28快照共133个官方条目，包含元流之子的多个职业条目；不把条目数等同于独立角色数。元流之子职业共享语音的映射在资源文档中明确记录。

已存档比赛依赖英雄ID。更新名单后如有英雄被移除，应先保留旧版资源与比赛存档，再决定是否迁移。

## 开发验证

```bash
cd /root/Course_THU/HOK-BP/vite-project
npm run build
npm test
npm run test:e2e
npm run verify:assets
```

浏览器测试默认使用当前WSL已有的Chromium，也可以用 `CHROME_PATH=/path/to/chrome npm run test:e2e` 指定。测试会使用独立浏览器上下文和5179端口，不改变5173端口上的真实比赛存档。

最新验证结果、截图与trace位于 `vite-project/test-results/`。资源校验记录位于 `vite-project/public/data/media-verification.json`。

## 分离入口与旧存档

- 首页 /：上方主屏，下方裁判区，可调主屏占比。裁判区滚动、切换设置及确认框不会遮挡主屏。
- /display：只显示比赛，适合扩展屏或 OBS 窗口采集（OBS 浏览器来源与 Chrome 不共享存档）；旧地址 /?display=1 仍兼容。
- /control：独立裁判入口。与首页下方裁判区互斥，同一时间只允许一个控制端写入；使用此入口前关闭首页。
- 当前同步限同一电脑、同一浏览器配置及同源页面，不是远程 HTTP 控制 API。
- 已开始的旧版存档保留原有顺序；新建系列赛后使用新规则。空白旧存档自动升级。
